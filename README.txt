TicketFlow — HTML, CSS and JavaScript only

This is the original TicketFlow frontend interface retained with a localStorage-based demo data layer instead of Express.js and MongoDB. No backend, Node.js, or database setup is required.

Run:
1. Extract this ZIP.
2. Open index.html in a modern browser (or use VS Code Live Server).
3. Sign in with one of these demo accounts:
   Admin: admin@ticket.com / admin123
   Staff: staff@ticket.com / staff123
   User: user@ticket.com / user123

Important:
- The interface and styling are retained.
- Data is stored only in this browser's localStorage; it is not shared across browsers/devices and clearing site data will remove it.
- This static version is for demonstration. It does not provide secure authentication or a shared MongoDB database.
